Norte Servic — SEO básico para Google Search Console

Arquivos criados:
- public/sitemap.xml
- public/robots.txt

Também foram adicionadas tags canonical nas páginas principais.

Como usar no Google Search Console:
1. Suba o projeto para o GitHub/Railway.
2. Abra no navegador:
   https://www.norteservic.com.br/sitemap.xml
   Ele precisa começar com:
   <?xml version="1.0" encoding="UTF-8"?>
3. No Search Console, vá em:
   Sitemaps
4. Envie somente:
   sitemap.xml

Importante:
- Não envie https://www.norteservic.com.br/ como sitemap.
- A página inicial é HTML; sitemap precisa ser XML.
- As páginas individuais devem ser usadas em Inspeção de URL, não em Sitemaps.
